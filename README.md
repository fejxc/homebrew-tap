# Fejxc Tap

## How do I install these formulae?

`brew install fejxc/tap/<formula>`

Or `brew tap fejxc/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "fejxc/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
